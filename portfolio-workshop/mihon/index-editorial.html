Selected Works

公開しているアプリ・OSS・教材から、いま見てほしいものを並べています。番号の行を押すと公開先へ移動します。

  1. 01

    PetTrack

    ペットの食事・散歩・健康記録を、家族みんなで続けられるアプリ。

    MVVM で画面とデータの責務を分け、Firebase Authentication と Cloud Firestore で家族間のリアルタイム共有を実現。企画から設計・実装・審査提出まで一人で対応し App Store に公開。

    Swift ／ SwiftUI ／ Firebase ／ MVVM

    スマホアプリ（iOS） 2025.11 App Store↗
  2. 02

    ScanGuard

    書類を共有する前に、写り込んだ個人情報を AI が自動で見つけて隠すアプリ。

    Apple の Vision と AI で、顔・氏名・電話番号・マイナンバーなど 30 種類以上の個人情報を画像から検出してマスキング。すべて端末内で処理し、外部にデータを送らない設計。

    Swift ／ SwiftUI ／ Vision

    スマホアプリ（iOS） 2025.11 App Store↗
  3. 03

    cc-DevelopmentTeam

    個人開発に「設計・開発・レビュー・テスト・セキュリティ」の 5 部署をつける仕組み。

    Claude Code のサブエージェント 5 体と 13 個のスラッシュコマンドで、チーム開発の流れを一人でも回せるようにしたプラグイン。仕様書なしで作り始めても、完了時に仕様書が自動で書き戻される。

    Claude Code ／ Markdown ／ Bash

    自動化ツール（Claude Code プラグイン・OSS） 2026.05 GitHub↗
  4. 04

    Nimbus

    Claude Code のエージェントを操縦するためのコックピット IDE。

    Code - OSS を土台に、Claude Code のセッション・承認・並列タスク・コストを 1 つの画面で見渡せるようにした非公式の独立プロジェクト。導入手順ページを GitHub Pages で公開。

    TypeScript ／ Electron ／ Claude Code

    デスクトップアプリ（OSS・開発中） 2026.08 導入ページ↗
  5. 05

    my-secretary

    フォルダを開くだけで出迎えてくれる、自分専用の AI 秘書（ワークショップ配布プラグイン）。

    朝会・夕会・週次レビュー、締切と返事待ちの管理、人物メモと打ち合わせ準備、代筆までを Claude Code のスキルとフックで実装。DMM のワークショップ題材を「後から育てられる資産」として公開。同じ狙いで proposal-slidekit（商談メモ→提案書）、competitor-researcher（競合調査）も公開。

    Claude Code ／ Python ／ Skills / Hooks

    自動化ツール（Claude Code プラグイン・OSS） 2026.07–09 GitHub↗
  6. 06

    AIアプリ開発入門ゼミ受講生向けサイト

    DMM のゼミ全 7 回の教材・演習を 1 か所にまとめた受講生向けサイト。

    カリキュラムの正本（Markdown）から公開ページを生成する仕組みにして、教材の修正がサイトに素直に反映されるようにした。実機スクリーンショットと図解つき。GitHub Pages で公開。

    HTML / CSS ／ Python ／ Claude Code ／ GitHub Pages

    Web サイト 2026.09 サイト↗
  7. 07

    スペースインベーダー（ワークショップ教材）

    プログラミング未経験者が 60 分で作れる、Claude Code のゲーム制作ワークショップ。

    HTML 1 ファイルで動くレトロなインベーダーを題材に、「小さく頼んで・遊んで確かめて・次へ」の型で進める手順書を作成。防御壁・UFO・効果音まで入った完成見本つき。

    Claude Code ／ HTML / JavaScript（Canvas）

    学習の成果物（ブラウザゲーム・教材） 2026.08 DMM 生成AI CAMP で開催
  8. 08

    ゼミ告知の見出し画像シリーズ

    ペンギン先生が案内する、ゼミ 4 種 × 期ごとの告知バナー。

    画像生成 AI でキャラクターを出し、日本語の文字は Pillow で合成する分担にして文字崩れを防いだ。同じ仕組みで書籍の販促 POP と LP の自動生成システムも制作。

    画像生成 AI ／ Python（Pillow） ／ Codex

    画像・デザイン 2026.09 DMM 生成AI CAMP のコミュニティで掲示

宮﨑竜治について

About

営業からテスターへ、そして組込み・バックエンド・アプリ開発と生成AI の講師へ。歩いてきた道と、いま使える道具です。

Profile

大学卒業後、三菱電機ITソリューションズでコンサルティング営業を担当し、5 エリアの代理店で売上目標を継続達成。2022 年に富士ソフトへ転職し、テスターからキャリアを始めて、Go でのバックエンド開発、C++ による組込み機器の主担当、Flutter でのアプリ開発へと担当領域を広げてきました。

並行して生成AI の実務にも取り組み、DMM 生成AI CAMP では Claude Code／Dify のゼミ講師として、3 か月・全 13 回のゼミをのべ 6 クラス担当。受講生の理解度を測る学習管理システムも自作して本番運用しています。「自分で作れる」と「人に教えられる」を両輪に、AI で人のキャリアを前に進める仕事をしていきたいと考えています。
